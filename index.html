Duas distribuições Debian, dois propósitos opostos. Este relatório compara instalação, consumo de recursos, desempenho de CPU/memória e aplicações reais em máquinas virtuais configuradas com hardware idêntico.

Mesma base, públicos opostos

user@ubuntu:~

Ubuntu — distribuição de base Debian voltada a um amplo conjunto de cenários: computadores pessoais, desenvolvimento e ambientes corporativos.

A versão 26.04 é uma edição LTS (Long Term Support), com evolução do ambiente GNOME e dos componentes do sistema.

root@kali:~

Kali Linux — também de base Debian, direcionado a segurança da informação: pentest, auditoria, forense e análise de vulnerabilidades.

A versão 2026.2 atualiza kernel, ambiente XFCE e ferramentas especializadas de segurança.

O laboratório por trás dos números

◱

Virtualização

Recursos como CPU, memória e disco são disponibilizados de forma controlada a um sistema convidado — permitindo padronizar os limites de hardware entre as duas distribuições testadas.

▣

VMware Workstation

Hipervisor de desktop usado para criar e executar as VMs, apropriado para laboratórios comparativos num mesmo computador físico.

◈

htop

Visualizador interativo de processos — usado aqui para observar o consumo de RAM e CPU em condição ociosa e durante o uso de aplicações.

▤

sysbench

Benchmark multithread com testes de CPU (cálculo de números primos) e memória (throughput em MiB/s) — o motor dos resultados a seguir.

Compilação e execução em C

Programa em C compilado com o GCC e cronometrado com time nas duas distribuições: percorre o intervalo de 500 a 1500 e imprime os valores que, divididos por 7, deixam resto igual a 3.

programa.c
#include <stdio.h>
int main()
{
    printf("Numeros entre 500 e 1500 que divididos por 7 deixam resto igual a 3:");
    for(int i=500;i<=1500;i++){
        if(i%7==3){
            printf("\n%d", i);
        }
    }
    return 0;
}

Um jogo de compensações

Ubuntu 26.04.1 uso geral
  • +Menor espaço em disco: 8,6 GB
  • +Experiência desktop ampla (GNOME)
  • +Compilação do programa em C mais rápida (0,048s)
  • −Levemente atrás nos testes sintéticos
Kali Linux 2026.2 segurança
  • +Menor RAM em estado ocioso (762 MB)
  • ++1,87% em eventos de CPU/s
  • ++1,82% em taxa de transferência de memória
  • −Maior espaço em disco: 15,6 GB

A finalidade de uso pesa mais do que poucos pontos percentuais de benchmark: uso geral (Ubuntu) versus segurança da informação (Kali). Nas aplicações reais, Nmap e Firefox tiveram tempos próximos; o VS Code exige nova medição em condições controladas.
